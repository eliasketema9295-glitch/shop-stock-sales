Safety by default

The AI can't sell you what you don't have.

An MCP tool cannot pause and wait for the user, so every write is two calls. The same pattern covers `record_sale` and `restock_product`.

01

Preview

The tool is called without confirm. The API returns the items, prices, total, projected stock, and a short-lived token tied to those exact items. Nothing is saved.

02

Confirm

Called again with confirm: true, the token, and a unique ID. The API re-checks stock and saves the sale and its stock movements in one transaction.

03

Retry safely

If the same ID arrives again, the API returns the original result instead of saving a duplicate. Idempotent by design.

// The REST API (Fastify + Drizzle)
import Fastify from "fastify";
import { drizzle } from "drizzle-orm/node-postgres";
import { products } from "./db/schema.js";

const app = Fastify({ logger: true });

app.get("/products", async (request, reply) => {
  // Fetch all products from PostgreSQL
  const allProducts = await db.select().from(products);
  return { data: allProducts };
});
// The MCP Server (Translator for Claude)
server.tool(
  "check_stock",
  "Fetches the current products from the shop API",
  {},
  async () => {
    // Call our Fastify API!
    const response = await fetch("http://localhost:3000/products");
    const data = await response.json();
    
    const productList = data.data.map((p) => 
      `${p.name}: ${p.stockQuantity} in stock`
    ).join("\n");

    return { content: [{ type: "text", text: productList }] };
  }
);
MCP Tools

Seven tools Claude can call.

Five read-only, two that write. Every write is labelled in its description.

search_productsread

Find products by name or SKU. Returns price and current stock.

check_stockread

Stock level for a product, with LOW / OUT OF STOCK flags and reorder level.

low_stock_reportread

Products at or below reorder level (or a custom threshold), with supplier.

sales_summaryread

Totals for a period, grouped by day or by product.

top_selling_productsread

Best sellers by units or revenue over any date range.

record_salewrites

Records a sale and reduces stock. Preview first (confirm=false, the default); only writes with confirm=true.

restock_productwrites

Adds received units to stock. Add-only — cannot reduce or overwrite.
